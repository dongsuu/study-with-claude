# W1-S1 · 문제 1. 출력 예측 (10문항)

`snippets.js`의 스니펫 10개를 **실행하지 말고** 읽기만 한 뒤, 각 스니펫에서 `log`되는 값을 `predictions.js`에 적으세요.

## 규칙
- `snippets.js`는 수정하지 않습니다.
- 값은 실제 JS 값으로 적습니다. `undefined`와 `'undefined'`는 다릅니다.
- 에러가 나면 그 지점에서 스니펫이 끝납니다. 마지막 원소로 `throws('ReferenceError')`처럼 적습니다.
- 각 예측 위에 **이유를 한 줄 주석**으로 남깁니다. (선언 단계 / 실행 단계 중 어디서 결정되는지)
- **10개를 모두 적은 뒤에** 테스트를 돌립니다.

## 실행
```bash
npm test -- js/01-scope-closure/s1-predict
```

틀린 문항은 테스트 diff로 정답이 보입니다. 정답을 보고 바로 고치지 말고, **왜 틀렸는지 이유를 먼저 주석에 적고** 피드백을 요청하세요.
